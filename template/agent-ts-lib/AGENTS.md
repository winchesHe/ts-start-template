# AGENTS.md

## 仓库概览

TypeScript 库项目，使用 tsdown 打包，ESM only。

## 验证命令

所有改动后必须运行：

```sh
pnpm check
```

该命令依次执行 typecheck → test → lint。三者全过才算验证通过。

## 代码风格

### 核心原则

1. **保持功能不变**：只改写法，不改行为。所有原始功能、输出和行为必须保持完整。

2. **清晰优于简短**：
   - 避免嵌套三元运算符，用 if/else 或 switch
   - 选择显式而非隐晦——清晰的代码优于过度紧凑的代码
   - 不要把过多关注点塞进单个函数或组件

3. **函数风格**：
   - 顶层函数使用 `function` 关键字，不用箭头函数
   - 顶层函数必须有显式返回类型标注
   - 使用 ES modules，import 排序整齐

4. **精简复杂度**：
   - 减少不必要的嵌套和间接层
   - 消除冗余代码和过度抽象
   - 移除描述显而易见代码的注释
   - 合并相关逻辑

5. **避免过度简化**：
   - 不要创造"聪明但难懂"的方案
   - 不要移除有助于代码组织的合理抽象
   - 不要为了"更少行数"牺牲可读性和可调试性

## Commit 规范

- 使用 conventional commits：`feat:` / `fix:` / `chore:` / `refactor:`
- 每个 commit 只做一件事
- 消息用英文，简洁明了

## 禁止事项

- 不要引入未 pin 版本的依赖（使用 `^` 指定最低版本）
- 不要添加非必要的运行时依赖
- 不要修改 `memory/process.md` 以外的 memory 文件结构
- 不要跳过 `pnpm check` 直接提交
